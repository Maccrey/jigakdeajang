Apps Script 웹 앱을 연결하면 이 브라우저의 출퇴근기록을 개인 스프레드시트로 동기화할 수 있습니다.

Google Sheets 연결 안내

내 스프레드시트에 안전하게 연결하기

  1. 새 Google 스프레드시트를 만들거나 기존 시트를 엽니다.
  2. 확장 프로그램 → Apps Script를 열고 저장소의 google-apps-script.gs 내용을 붙여넣고 저장합니다.
  3. 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 나, 액세스 권한은 본인 환경에 맞게 선택하고 배포합니다.
  4. 배포된 웹 앱 URL을 복사해 이 설정 화면에 붙여넣고 URL 저장, 연결 확인을 누릅니다.
  5. 처음에는 Google 권한 승인 화면이 나올 수 있습니다. 검토한 뒤 본인이 소유한 스프레드시트와 스크립트만 승인하세요. 이 정적 웹 앱은 로그인 토큰을 보관하지 않으므로, 본인 전용 시트라면 배포 액세스가 실제로 제한되는지 확인하고 URL을 외부에 공유하지 마세요.

이 Apps Script 예제에는 사용자별 로그인이나 비밀키 검증이 없습니다. 웹 앱을 “모든 사용자”로 공개하면 URL을 아는 사람이 시트의 출퇴근·일정·설정 데이터를 덮어쓸 수 있습니다. 민감한 개인 데이터에는 공개 배포를 피하고, 시트와 앱을 신뢰하는 사용자만 URL을 공유하세요. 브라우저 앱이므로 동기화는 사용자가 직접 실행하며, 시트의 기록은 앱의 브라우저 저장 데이터와 별도로 보관됩니다.
